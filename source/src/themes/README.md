`tokens.css` defines the initial default palette; keep it consistent with `PALETTES.enhanced` in `palettes.ts`. `spectrum-enhanced.css` maps extension tokens to verified Spectrum variables and is gated by the base-theme scope. Sixteen built-in presets are resolved by shared settings and applied as inline root variables; users can optionally override the accent colour. The separate highlight token styles developer-thread markers and remains gold for legacy presets. Legacy saved `custom` theme IDs fall back to Spectrum Enhanced.
