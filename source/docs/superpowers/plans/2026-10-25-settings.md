# Phase 5 settings implementation plan

Preserve the approved desktop defaults. Add shared validated settings and preset palettes, a dependency-free popup, and a storage-change content controller. Save under one versioned `chrome.storage.local` key; never clear unrelated data. Apply root attributes/variables without observing site DOM. Wrap each styling module in CSS `@scope` so disabling it also restores dynamically loaded native content.

- [x] Test validation, defaults, palette resolution, save/reset isolation, change propagation and initial-load races before implementation.
- [x] Implement seven themes, accent/custom colours, width, density, body font size, avatar shape and switches for implemented modules.
- [x] Wire scoped CSS and storage permission; keep full-width defaults and existing site selectors. Target Chromium 118+ for `@scope`.
- [x] Verify only settings-related TS, unit/integration cases, affected packaging and popup/content fixtures, including errors and reset. Update documentation and version.
