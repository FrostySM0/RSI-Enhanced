## Cross-page pledge data tools

The expandable Hangar tools panel shares the same normalized, read-only index as text search. It can filter all indexed pledge pages by item type, LTI, giftable/reclaim status, Warbond and melt value. Search results and live pledge cards show IDs, base pledge names and values only when the Hangar page supplies them. CSV includes pledge details across all pages; Hangar Transfer JSON uses the published HangarXPLOR ship fields and explicitly flags generated ship codes that were not resolved against a catalogue.

Hangar pages are indexed only after the user searches, filters, exports, refreshes, or selects a cross-page view. A previously saved cross-page display or Ship Paint mode can also request the needed pages when Hangar opens. The scan is sequential, read-only and same-origin; the native page stays usable during it. A complete index is valid for 15 minutes, bound to a fingerprint of the first Hangar page and page count. Later actions can use that cache immediately. Once expired, it is not reused and is removed the next time an indexing action checks it; until then, the expired copy may remain in local storage. The Refresh all pages button invalidates only this index key and rebuilds it. If Ship Paint filtering or a larger page-size view needs native card nodes, it fetches those pages even when metadata is cached; loaded native pledge cards are combined and paginated locally. No raw page markup, pledge actions or remote APIs are involved.
