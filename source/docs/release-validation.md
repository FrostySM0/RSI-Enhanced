# Local validation

This extension targets public distribution in Chromium desktop browsers. The versioned records below describe checks performed for each package and do not replace current Chrome and Edge validation.

## Reproducible package check

Run `pnpm build`, then `pnpm check:release`. The checker verifies version consistency, Manifest V3 configuration, RSI host matching, the storage-only API permission, local packaged assets, absence of fixture files, classic content-script syntax, and that the bundle does not use `setInterval`, `XMLHttpRequest` or `eval`. It reports uncompressed asset sizes. It does not run feature tests, measure live CPU use, or prove RSI interactions work.

## Manual Chrome and Edge checks still required

- Reload the unpacked `dist` extension and refresh RSI pages. Check the settings switches and verify each feature can be disabled independently.
- Check forum lists, original posts, nested replies, images, collapse controls and reply controls at your desktop resolution. Confirm full width and prominent avatars.
- Check chat scrolling, channel switching, mentions, attachments and composer focus. Verify native Online Users rows and statuses remain unchanged.
- Open the bell popup and verify filters, moderation highlighting, avatar shapes, row hiding and clear/hide controls. Change theme and confirm moderation highlighting stays amber.
- Change a Spectrum module switch, save, then reopen the popup. Confirm preferences persist and Reset affects only settings storage. Saved-thread and hidden-user data should remain intact after appearance resets.
- Check Pledge Store, Ship Matrix, Organizations, Comm-Link, Account/Profile and My Hangar. Toggle each independently; check native artwork, search/sort/scroll and navigation. Purchases or organization changes are unnecessary for validation.
- Visit checkout and unrelated financial/security routes; section styling must remain inactive. Account/Profile and My Hangar styling has separate route scopes; signed-in live appearance remains unverified.
- Inspect extension errors and the page console. Record browser version, desktop resolution, affected URL and a screenshot for any issue.

No authenticated live browser inspection was performed for this validation. Local fixtures and packaged-artifact checks do not establish cross-browser behavior.
