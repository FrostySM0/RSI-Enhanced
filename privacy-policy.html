RSI Enhanced Privacy Policy

Last updated: November 26, 2026

RSI Enhanced changes the appearance of supported Roberts Space Industries pages and provides optional tools for Spectrum and the RSI website. The extension keeps its settings and saved feature data in your browser. The developer does not receive that data.

Information RSI Enhanced uses

The extension reads relevant content from RSI pages when needed to apply your selected appearance and operate enabled features. Depending on the features you use, that content can include forum posts and thread titles, visible notification text, the Messages list structure and unread counts, and Hangar pledge or item details. My Hangar and the Personal Dashboard can read the Concierge rank, progress, and status fields shown on your RSI account dashboard while those views are open. The Messages panel summary and the dashboard's live Spectrum snapshot read conversation rows and unread counts; the dashboard reads those counts only while it is open on Spectrum. They do not read or save private message text.

The extension stores the following information in your browser's local extension storage on your device:

  • Your appearance, layout, and feature settings, plus the version of this privacy notice you accepted.
  • Spectrum forum links, titles, and save times for threads you choose to save, plus any folders, tags, pin state, and private notes you add to those saved discussions.
  • Named Spectrum Advanced Search presets you explicitly save. Each preset contains the search phrase and selected community, result types, time range, author, role, and sort order. Presets remain in local extension storage until you delete them.
  • Handles and display names for users you choose to hide, including the extension's built-in J3PT setting.
  • Roadmap cards you choose to watch, locally recorded Roadmap card snapshots, scan times and change history, and a compact cached snapshot of public next-patch cards for the Personal dashboard.
  • Hangar favourites, view/page-size choices, and any saved Hangar views you create. A saved view stores its name, search text, filters, and sort order in local extension storage. Collections stores collection names and the pledge IDs for whole Hangar cards you assign to each collection in local extension storage; it uses the existing Hangar index and does not create another index or fetch pledge details. You can delete collections from My Hangar. On your first My Hangar visit, or when you open the Personal Dashboard without a valid index, the extension automatically builds a local index of pledge and item identifiers, names, details, dates, visible values, item types, and image links. It reuses that index for up to 24 hours. A compact list of normalized ship and vehicle item names is derived from that index and used only on standalone pledge pages to mark variants found in that local Hangar index. The summary has the same 24-hour expiry. When needed for a cross-page display, sanitized fragments of visible Hangar cards may also be stored. The fragments omit scripts, forms, controls, hidden fields, event handlers, and link destinations. When you manually refresh the Hangar index, the extension compares the completed index with a compact previous snapshot stored locally to show added, removed, or changed pledges. That snapshot contains pledge identifiers and display names plus short fingerprints of visible contents, values, and pledge options needed for comparison; it does not retain a second copy of the contents. The comparison runs only after you request a refresh; there is no background polling. The snapshot is replaced after a successful manual refresh, and the report is kept locally until the next successful refresh or until you clear cached data.
  • When you use the Ship Upgrade Planner, the source and target hulls you select for saved plans. Public hull reference prices are fetched on demand and kept in memory only; they are not saved. The SC Wiki API is checked first for a public USD standalone MSRP and a separately labeled warbond SKU, with its snapshot date and availability flags. If the API has no usable price, the planner checks the current RSI pledge listing. If neither public source has a source-hull price, it may use the selected Hangar row's recorded pledge value as a clearly labeled local estimate when its value includes a matching ISO currency code; a package value can include other items and is not the standalone hull value or RSI upgrade credit. Bare dollar symbols without a confirmed currency are displayed for reference only and are not used to calculate a comparison. Manually entered prices from an earlier planner version are removed when saved plans load.
  • Cached public funding history and yearly totals used by Funding Goals.

Verse Data Hub search phrases and selected categories are sent only when you search. Search results and any selected-record details stay in memory and are not saved as search history.

A small amount of temporary navigation state, such as a selected Hangar filter, the Spectrum reply you chose to open, or the ID and target community path for a saved search being applied across communities, may be held in the RSI tab's session storage. A pending saved-search action is removed after use or expires within two minutes; this temporary state is used only to complete that in-tab action.

When information leaves your device

RSI Enhanced does not send your saved settings, named Spectrum Advanced Search criteria, hidden-user list, saved threads (including their local folders, tags, pins, and notes), Hangar favourites, Collections names or whole-card pledge memberships, Hangar index, ownership-name summary, or Hangar change snapshot and report to the developer. Collections reads the existing index locally on RSI pages; collection data is not sent to the Ship Matrix service or another external service. RSI Enhanced has no analytics or telemetry and does not operate a server that receives this information.

Some optional features make requests to robertsspaceindustries.com for RSI page or Spectrum reply data. On first use or after the index expires, My Hangar or the Personal Dashboard requests Hangar pages sequentially to build the local index; search and refresh can request additional pages. My Hangar and the Personal Dashboard also read Concierge progress from the RSI account dashboard while those views are open. These requests use the current RSI tab and may use the RSI sign-in session already active in your browser. Dev Tracker or Extend conversation can request reply context. When the Personal Dashboard opens, it may request a public Roadmap snapshot from RSI without browser credentials if the saved snapshot is missing or older than six hours. The request does not include the cards you watch or your locally recorded scan and change history. When you first search or use filters in Roadmap Release View, it also requests RSI's public Roadmap board once without browser credentials; the board is held in page memory to search cards locally, and the words you enter are not sent. The full board is not saved. The extension does not read or store your password or session cookies, and it does not use these requests to post or change account data.

On Spectrum, when a member profile card links to a Citizen Dossier, RSI Enhanced requests that member's public RSI dossier to display the Enlisted date. RSI receives the dossier handle in the request URL. This read-only request omits browser credentials and the referrer. The extension parses the dossier locally and holds only the extracted Enlisted date or an unavailable result in extension memory, for up to five minutes for a date or 30 seconds when no date is available; results are capped at 128 and are never saved to storage or sent to the developer or another service.

When you open the Ship Upgrade Planner, it reads your existing local Hangar index and requests public ship names and capability details from RSI's Ship Matrix. For each selected hull, the extension worker first sends only the selected public ship name and manufacturer to api.star-citizen.wiki to request its game-vehicle and Ship Matrix pricing records. That fixed read-only request omits browser credentials and does not include your Hangar index, pledge records, package title, saved plans, or RSI sign-in data. If the API has no usable price, the planner checks that hull's public RSI pledge listing on demand. The returned USD MSRP is the standalone reference; eligible warbond SKUs and their availability flags are displayed separately with the API snapshot date. The values may lag the live store and are not an RSI CCU quote. If neither public source has a source-hull price, the planner uses the selected Hangar row's recorded value locally only when it includes an ISO currency code matching the indexed currency. When an RSI price has a currency symbol but no confirmed currency code, the planner displays it for reference but does not calculate a comparison; a bare dollar symbol is ambiguous. Package values may include other items and are labeled as estimates, not RSI upgrade credit or an official quote. Saved plans contain only the selected hulls and stay in local extension storage. Public hull reference prices are not saved.

When a standalone ship or vehicle pledge page has related variants, the extension worker uses the linked RSI ship-profile URL locally to match the current model against Ship Matrix records. Its fixed request to api.star-citizen.wiki includes only the public manufacturer name as a filter; the profile URL is not sent to that service. The request omits browser credentials and the referrer and includes no Hangar holdings, pledge values, account details, saved plans, or sign-in data. Matching comparison data is held in extension memory for up to 15 minutes and is not saved to storage.

Verse Data Hub is available from its launcher on RSI pages while the extension is enabled. It contacts api.star-citizen.wiki only after you enter a search of at least two characters. The selected category and search phrase are sent to fixed public reference-data endpoints; an All search checks the unified game-data search plus the manufacturer and Galactapedia indexes. Choosing a result may request that record's public details. These requests omit browser credentials and the referrer, and do not include Hangar contents, pledge details, or RSI account information. The open panel keeps active search text and results in page memory. In addition, the extension worker temporarily caches search phrases and results in volatile memory with a 60-second reuse window and selected-record details with a five-minute reuse window. Expired cache entries are not reused but may remain in worker memory until the same entry is requested again, the cache evicts an entry, or the worker stops. Closing the panel does not immediately clear those worker caches; they are not saved in extension storage or search history. The Wiki API may receive ordinary connection information such as your IP address and request time under its own privacy practices.

The Firefox install disclosure identifies website content and website activity because optional features read relevant RSI page information and can make additional read-only requests to RSI as part of their use. Those requests go to RSI itself, not to the extension developer.

Funding Goals can request public historical figures from a Google Sheets document. Those requests omit browser credentials and do not include RSI account or Hangar information. Google may still receive ordinary connection information, such as your IP address, request time, and technical request details, under Google's own privacy practices.

RSI receives requests made to its website as part of using RSI Enhanced's optional features described above. The SC Wiki API receives selected public hull names and manufacturer names for planner price lookups, only public manufacturer names for standalone ship-family comparisons, and the search phrases and categories you enter in Verse Data Hub. Selecting a result can also request its public record details. Ship-profile URLs are matched locally and are not sent to the SC Wiki API. No external service is contacted for analytics, advertising, or user profiling.

Storage, retention, and deletion

Saved extension data remains in your browser's local extension storage until you remove it. Named Spectrum Advanced Search presets remain there until you delete them from the Saved searches menu or uninstall the extension. Collection names and whole-card pledge memberships remain there until you delete those collections or uninstall the extension. The Hangar index, its compact ownership-name summary, and any sanitized card fragments are reused for up to 24 hours; an expired copy can remain stored until the next indexing action replaces or removes it. The Hangar change snapshot and report remain local until a successful manual refresh replaces them or you clear cached data. The public Roadmap snapshot is refreshed when it is older than six hours and the Personal dashboard opens; watched cards and recorded changes remain stored locally. Funding history is cached locally and refreshed as the feature runs. Route snapshots and saved CCU routes from earlier versions, if present, remain on this device and are no longer read or transmitted by the current planner. Temporary tab state is kept in that tab's session storage.

You can remove individual saved searches, saved upgrade plans, saved threads, saved-thread folders, tags, pins, notes, hidden-user entries, Hangar favourites, Collections, or saved Hangar views with their feature controls. Clear cached data in settings lets you clear Hangar search data (the index, ownership summary, and sanitized card fragments), Hangar change tracking, Funding Goals history and totals, or the Personal Dashboard's cached public Roadmap snapshot individually; each cache is rebuilt or fetched when its feature next needs it. Clearing Hangar change tracking removes the previous comparison baseline and report, so a later manual comparison starts with a new baseline and the old report cannot be recovered. Clear all cached data removes all four groups. These actions leave settings, saved upgrade plans, Hangar favourites, Collections, saved views, Spectrum saved searches and discussions, hidden-user choices, and the Roadmap watchlist and change history in place. Reset defaults resets appearance and feature preferences; it does not erase saved lists or caches. Expired Hangar copies can remain until the next indexing action. Funding history is refreshed by the feature and pruned to a rolling 400-day window when new history is saved; yearly totals are replaced when refreshed. To remove all extension-local data, uninstall RSI Enhanced from your browser. RSI Enhanced does not keep a separate copy on a developer-operated server.

Sharing and sale

The developer does not sell or transfer user data to third parties, use it for purposes unrelated to the extension's features, or use it to determine creditworthiness or for lending. The extension does not share stored user data with the developer. The network requests described above go to RSI for RSI content, to the SC Wiki API for selected public ship prices, ship-family data and user-initiated Verse Data Hub searches, and to Google for the public funding spreadsheet.

Limited use

RSI Enhanced uses information it accesses only to provide or support the user-facing features described in this policy. The extension does not use it for advertising or personalized advertising, sell it, or share it with data brokers. Its network requests are limited to RSI page and reply data needed by optional features, public ship-price and ship-family lookups to the SC Wiki API, user-initiated public reference searches using the phrase and category you enter, and public funding figures from the Google Sheet described above. This use is consistent with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Changes to this policy

This policy may be updated if the extension's data handling changes. When the in-extension notice version changes, the settings page will show the policy again and ask you to agree before the features run.
