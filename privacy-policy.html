RSI Enhanced Privacy Policy

Last updated: November 11, 2026

RSI Enhanced changes the appearance of supported Roberts Space Industries pages and provides optional tools for Spectrum and the RSI website. The extension keeps its settings and saved feature data in your browser. The developer does not receive that data.

Information RSI Enhanced uses

The extension reads relevant content from RSI pages when needed to apply your selected appearance and operate enabled features. Depending on the features you use, that content can include forum posts and thread titles, visible notification text, the Messages list structure and unread counts, and Hangar pledge or item details. My Hangar and the Personal Dashboard can read the Concierge rank, progress, and status fields shown on your RSI account dashboard while those views are open. The Messages panel summary and the dashboard's live Spectrum snapshot read conversation rows and unread counts; the dashboard reads those counts only while it is open on Spectrum. They do not read or save private message text.

The extension stores the following information in your browser's local extension storage on your device:

  • Your appearance, layout, and feature settings, plus the version of this privacy notice you accepted.
  • Spectrum forum links, titles, and save times for threads you choose to save, plus any folders, tags, pin state, and private notes you add to those saved discussions.
  • Handles and display names for users you choose to hide, including the extension's built-in J3PT setting.
  • Roadmap cards you choose to watch, locally recorded Roadmap card snapshots, scan times and change history, and a compact cached snapshot of public next-patch cards for the Personal dashboard.
  • Hangar favourites and view/page-size choices. On your first My Hangar visit, or when you open the Personal Dashboard without a valid index, the extension automatically builds a local index of pledge and item identifiers, names, details, dates, visible values, item types, and image links. It reuses that index for up to 24 hours. When needed for a cross-page display, sanitized fragments of visible Hangar cards may also be stored. The fragments omit scripts, forms, controls, hidden fields, event handlers, and link destinations.
  • When you use the Ship Upgrade Planner, the source and target hulls you select for saved plans. Public hull reference prices are fetched on demand and kept in memory only; they are not saved. The SC Wiki API is checked first for a public USD standalone MSRP and a separately labeled warbond SKU, with its snapshot date and availability flags. If the API has no usable price, the planner checks the current RSI pledge listing. If neither public source has a source-hull price, it may use the selected Hangar row's recorded pledge value as a clearly labeled local estimate when its value includes a matching ISO currency code; a package value can include other items and is not the standalone hull value or RSI upgrade credit. Bare dollar symbols without a confirmed currency are displayed for reference only and are not used to calculate a comparison. Manually entered prices from an earlier planner version are removed when saved plans load.
  • Cached public funding history and yearly totals used by Funding Goals.

A small amount of temporary navigation state, such as a selected Hangar filter or the Spectrum reply you chose to open, may be held in the RSI tab's session storage. It is used to complete that in-tab action.

When information leaves your device

RSI Enhanced does not send your saved settings, hidden-user list, saved threads (including their local folders, tags, pins, and notes), Hangar favourites, or Hangar index to the developer. It has no analytics or telemetry and does not operate a server that receives this information.

Some optional features make requests to robertsspaceindustries.com for RSI page or Spectrum reply data. On first use or after the index expires, My Hangar or the Personal Dashboard requests Hangar pages sequentially to build the local index; search and refresh can request additional pages. My Hangar and the Personal Dashboard also read Concierge progress from the RSI account dashboard while those views are open. These requests use the current RSI tab and may use the RSI sign-in session already active in your browser. Dev Tracker or Extend conversation can request reply context. When the Personal Dashboard opens, it may request a public Roadmap snapshot from RSI without browser credentials if the saved snapshot is missing or older than six hours. The request does not include the cards you watch or your locally recorded scan and change history. The extension does not read or store your password or session cookies, and it does not use these requests to post or change account data.

When you open the Ship Upgrade Planner, it reads your existing local Hangar index and requests public ship names and capability details from RSI's Ship Matrix. For each selected hull, the extension worker first sends only the selected public ship name and manufacturer to api.star-citizen.wiki to request its game-vehicle and Ship Matrix pricing records. That fixed read-only request omits browser credentials and does not include your Hangar index, pledge records, package title, saved plans, or RSI sign-in data. If the API has no usable price, the planner checks that hull's public RSI pledge listing on demand. The returned USD MSRP is the standalone reference; eligible warbond SKUs and their availability flags are displayed separately with the API snapshot date. The values may lag the live store and are not an RSI CCU quote. If neither public source has a source-hull price, the planner uses the selected Hangar row's recorded value locally only when it includes an ISO currency code matching the indexed currency. When an RSI price has a currency symbol but no confirmed currency code, the planner displays it for reference but does not calculate a comparison; a bare dollar symbol is ambiguous. Package values may include other items and are labeled as estimates, not RSI upgrade credit or an official quote. Saved plans contain only the selected hulls and stay in local extension storage. Public hull reference prices are not saved.

The Firefox install disclosure identifies website content and website activity because optional features read relevant RSI page information and can make additional read-only requests to RSI as part of their use. Those requests go to RSI itself, not to the extension developer.

Funding Goals can request public historical figures from a Google Sheets document. Those requests omit browser credentials and do not include RSI account or Hangar information. Google may still receive ordinary connection information, such as your IP address, request time, and technical request details, under Google's own privacy practices.

RSI receives requests made to its website as part of using RSI Enhanced's optional features described above. The SC Wiki API receives only selected public hull names and manufacturer names for planner price lookups. No external service is contacted for analytics, advertising, or user profiling.

Storage, retention, and deletion

Saved extension data remains in your browser's local extension storage until you remove it. The Hangar index and any sanitized card fragments are reused for up to 24 hours; an expired copy can remain stored until the next indexing action replaces or removes it. The public Roadmap snapshot is refreshed when it is older than six hours and the Personal dashboard opens; watched cards and recorded changes remain stored locally. Funding history is cached locally and refreshed as the feature runs. Route snapshots and saved CCU routes from earlier versions, if present, remain on this device and are no longer read or transmitted by the current planner. Temporary tab state is kept in that tab's session storage.

You can remove individual saved upgrade plans, saved threads, saved-thread folders, tags, pins, notes, hidden-user entries, or Hangar favourites with their feature controls. Clear cached data in settings removes the Hangar index and sanitized card fragments along with cached public Funding Goals history and yearly totals; those caches rebuild when you use the related features. It leaves settings, saved upgrade plans, Hangar favourites, saved discussions, hidden-user choices, and Roadmap watchlist data in place. Reset defaults resets appearance and feature preferences; it does not erase saved lists or caches. Expired Hangar copies can remain until the next indexing action. Funding history is refreshed by the feature and pruned to a rolling 400-day window when new history is saved; yearly totals are replaced when refreshed. To remove all extension-local data, uninstall RSI Enhanced from your browser. RSI Enhanced does not keep a separate copy on a developer-operated server.

Sharing and sale

The developer does not sell or transfer user data to third parties, use it for purposes unrelated to the extension's features, or use it to determine creditworthiness or for lending. The extension does not share stored user data with the developer. The network requests described above go to RSI for RSI content, to the SC Wiki API for selected public ship prices, and to Google for the public funding spreadsheet.

Limited use

RSI Enhanced uses information it accesses only to provide or support the user-facing features described in this policy. The extension does not use it for advertising or personalized advertising, sell it, or share it with data brokers. Its network requests are limited to RSI page and reply data needed by optional features, public ship-price lookups to the SC Wiki API using selected hull names and manufacturers, and public funding figures from the Google Sheet described above. This use is consistent with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Changes to this policy

This policy may be updated if the extension's data handling changes. When the in-extension notice version changes, the settings page will show the policy again and ask you to agree before the features run.
