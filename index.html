What’s new in RSI Enhanced 1.2.1View release notes

Version 1.2.1 redesigns Spectrum member cards and makes profile actions easier to find.

CHANGED

  • Spectrum member cards use a compact layout with aligned name, handle, badges and statistics. Posts, Karma and Enlisted share a text baseline; Add Friend and Private Message have clear spacing. Profile links, quick messaging and accessible Block options remain available, including RSI's native Block action and optional Hide posts.
  • The Account Access panel follows the selected theme palette across its surfaces, text, borders, credits, links and controls while keeping presence indicators distinct.
  • Backup & restore uses compact backup, restore, cache, and reset controls. Resetting preferences asks for confirmation and leaves saved content and cached data intact. Clear Hangar search, Hangar change tracking, Funding Goals, and Roadmap caches individually or together; clearing Hangar change tracking starts a fresh baseline on the next manual refresh.
  • Gear pledge pages no longer show the Gear recommendation shelf or request the public Gear catalogue from product detail pages; the existing Gear browse pages and pledge details remain available.
  • The Personal Dashboard launcher and title bar use a matching dashboard panel icon.
  • The privacy notice explains that Roadmap Release View reads RSI's public board without sending search words and that Spectrum reads a public dossier to show Enlisted dates. Notice version 29 asks existing users to review the updated disclosure.

FIXED

  • Firefox Account Access consistently uses the selected theme palette, matching the rest of the RSI page.
  • Roadmap Release View search works while categories are collapsed; selecting a result opens the matching patch and category, then takes you to and highlights the card.
  • Spectrum member card statistics show the full Enlisted date within the card and use the selected Spectrum theme's colors.
  • My Hangar Concierge progress shows the approximate qualifying pledge spend remaining to the next rank, matching the Personal Dashboard.
  • Gear galleries and pledge-card backing surfaces use the selected theme instead of fixed blue backgrounds.
  • Pledge Store canvases and shared card-list surfaces use the selected theme across Merchandise, Add-ons, Paints, Packs, Gift Cards and other catalog pages in the Chrome and Firefox packages.
  • Pledge Store cart buttons use a narrower card column so discounted and original prices stay readable without moving the button to another row.
  • Gear catalog grid gutters and the top filter/sort controls use the selected theme palette instead of cyan surfaces; the control override now wins against RSI's more-specific cyan rule.
  • The country selector strip and RSI website footer follow the selected theme across their backgrounds, dividers, links, logos and launcher button, with the footer layout and native actions unchanged.
  • The Spectrum empty-thread panel and its native first-reply action use the selected theme instead of cyan surfaces.
  • Spectrum Enlisted profile results use a bounded in-memory cache, expire after a short period, and retry unavailable values after a cooldown.

Privacy, in plain language

Your saved choices stay in your browser.

Settings and saved feature data stay in your browser. RSI Enhanced has no analytics or telemetry and does not send saved data to the developer. Optional tools may request RSI page data, public ship prices from the SC Wiki API, or funding history from Google Sheets when you use them. Read the full policy for details.

Common questions

Questions worth asking.

Clear answers about AI, permissions and data before you install.

Was AI used to help build RSI Enhanced?＋

Yes. AI tools are used to assist development by helping draft, review code and use of a regression testing suite to make sure features and code work continuously through development. The developer decides what is accepted and released. AI is not part of the installed extension. It does not send your browsing data to an AI or data service. The source, release history and automated tests are public so you can inspect the shipped code.

How can I trust this extension?＋

RSI Enhanced is an independent community project, not made or endorsed by Roberts Space Industries or Cloud Imperium Games. You can inspect its public source code and release history on GitHub, check the publisher and permissions in the browser store listings, and read the privacy policy. It has no analytics or telemetry, and saved feature data is not sent to the developer.

Browse source and releases ↗ Chrome Web Store ↗ Firefox Add-ons ↗ Read the privacy policy ↗
What information leaves my browser?＋

Saved settings and feature data stay in your browser and are not sent to the developer. Some optional features make requests to RSI or public sources such as the SC Wiki API and Google Sheets when you use them. For example, Verse Data Hub sends its search phrase and selected category to the SC Wiki API. The privacy policy lists each data flow.

See the full data-flow details ↗
Which permissions does RSI Enhanced request?＋

It requests the browser’s storage permission for settings and saved feature data, plus site access to robertsspaceindustries.com, api.star-citizen.wiki, and docs.google.com. These are used to style RSI pages and provide optional public game-data and funding features. Your browser’s store listing shows the requested permissions before installation.
