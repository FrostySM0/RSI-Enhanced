What’s new in RSI Enhanced 1.1.0View release notes

Release 1.1.0 brings a new settings dashboard with built-in release notes, expanded Spectrum and RSI tools, Firefox support, and improvements across My Hangar and the Pledge Store.

ADDED

  • The full-tab settings dashboard includes a Release notes section with the complete current release notes.
  • My Hangar indexes automatically on first use. Opening the Personal Dashboard builds the same browser-local index if it is missing or expired; both entry points reuse the valid 24-hour cache without duplicate Hangar-route indexing. Requests are sequential, read-only, and same-origin.
  • A full-tab settings dashboard with independent feature switches, live preference updates, searchable theme and font galleries, and settings backup and restore.
  • Forty new theme presets (61 total), including nine IAE event themes and OLED Gold.
  • The Personal Star Citizen dashboard brings together Hangar data, saved Spectrum discussions, the Roadmap watchlist, Funding Stats, and Concierge progress. Personal data stays in local browser storage.
  • Spectrum tools for saved threads, inline conversation context, author controls, notification filters, and saved-discussion organization. Timeline, Author rail, and Branch cards bring the reply-layout gallery to nine choices.
  • Spectrum forum threads mark the original author and their replies with a theme-independent gold OP badge.
  • Ten independently controlled RSI modules covering Account and Citizen Dossier, My Hangar, Pledge Store, Ship Matrix, Organizations, Comm-Link and Patch Notes, Roadmap, Funding Goals, Dev Tracker, and Terms of Service.
  • My Hangar fleet insights, List and Grid views, cross-page search and filters, favourites, exports, image previews, and a redesigned Hangar Log.
  • A Ship Upgrade Planner that compares ships against the full Ship Matrix catalog using public price references and saves plans on this device.
  • Expandable Advanced Funding History with monthly and annual charts using the existing public funding history.
  • Terms of Service comparison between previous and current wording.
  • A global ON/OFF control in the shared RSI and Spectrum header; saved module choices are preserved.
  • A Firefox desktop build alongside the Chromium build.

CHANGED

  • The privacy notice now describes automatic first-use Hangar indexing and Concierge progress lookups. Notice version 18 asks existing users to review the updated disclosure.
  • Supported RSI and Spectrum pages, shared headers, and navigation menus now follow the selected theme while retaining native navigation, account, and commerce controls.
  • Spectrum's Find a Guide page themes its backdrop, filters, tiles, cards, and controls while retaining RSI's hero artwork and dark side margins.
  • Funding Goals now uses the selected theme for its page background; the blue honeycomb and campaign-image layers are removed, and excess space above Funding Stats is reduced.
  • Roadmap Release View adds card search, category and status filters, watchlist controls, and card details. Roadmap status labels retain their established colours across themes.
  • The website feature gallery shows ten captioned views of Spectrum and RSI pages. Screenshots use different included themes, so their colours and accents vary.
  • Pledge Store, ship detail, Organizations, Comm-Link, Patch Notes, Dev Tracker, and Citizen Dossier pages receive clearer themed layouts while keeping native content and actions.
  • Spectrum forums and chat use theme-aware layouts, clearer reply and media controls, and improved desktop spacing while preserving native interactions.
  • Hangar indexing now requests pages through the signed-in RSI page's same-origin fetch context in Firefox and Chromium, with a 20-second request limit.
  • My Hangar page-size choices now match RSI's ten-item native page: 10, 20, 40, or All. Numbered views show the selected count when enough items remain, and older saved 9/18/36 choices migrate to 10/20/40.
  • Route-specific code and styles load only on relevant pages; optional features wait until opened. Improving extension performance and website page loading.

FIXED

  • Hangar favourites and package ship labels now handle titles nested inside RSI heading markup, and package stars can resolve pledge IDs from the containing card. A Hangar-scoped observer refreshes changed cards when RSI supplies summaries, pledge IDs, or ship details after activation, so package names, ship artwork, and favourite stars update without a manual refresh; it disconnects when Hangar enhancements are disabled.
  • Favourite controls now discover ship and package cards when RSI inserts extra wrappers between a Hangar list item and its row, keeping the star available on standalone ships and ship packages.
  • My Hangar and Personal Dashboard Hangar indexing retry temporarily unavailable pages up to three times. The My Hangar failure status identifies the page and response reason.
  • My Hangar normalizes filtered, sorted, paged, or extra-query URLs to the safe unfiltered page-one route before crawling, allowing it to discover every Hangar page.
  • Firefox My Hangar and Personal Dashboard indexing no longer stall on URLSearchParams iterator incompatibilities while validating page URLs.
  • My Hangar Concierge lookup rechecks progress after attaching its observer and reads the same-origin dashboard document without accessing Firefox's wrapped frame-window location.
  • My Hangar's quick Filters popover provides a category selector when RSI supplies no usable native options. Advanced type, status, and value filters narrow visible Hangar cards as well as search results and exports.
  • Saved Hangar ship and package favourites now stay at the top of the 10, 20, 40, and All item views, ahead of the selected sort order, even when the saved-favorites reference panel is present.
  • Standalone ship cards with RSI's native "Standalone Ships - Ship Name" title now show the favourite star before their details are expanded. The star also stays beside ship names on enhanced package headings.
  • Hangar package cards now show the contained current ship summary and update to its image when RSI loads ship details; disabling the module restores the pledge title and artwork. Ship and Upgrade filters now classify from pledge labels and item kinds, excluding unrelated rewards that mention "ship" and including "Upgrade - …" pledges. Saved indexes recalculate categories on read.
  • The Ships filter includes standalone ship and vehicle pledges plus ship/vehicle packages. The Packages filter shows only packages containing a ship or vehicle, excluding gear-only packages.
  • OP badges now use the selected Spectrum font while retaining their theme-independent gold treatment.
  • Light Spectrum forum themes now use readable contrast for post text, author names, timestamps, and sidebar labels; dark theme colors are unchanged.
  • Funding Goals number counters now use the selected font, matching the page text while preserving aligned tabular digits.
  • The dashboard now refreshes the complete next-patch card set from RSI's public Release View data when opened, without requiring a prior Roadmap visit. Scanning waits for lazy and incremental card rendering and preserves category states.
  • Standalone ship pledge galleries and purchase panels now use the selected theme's surfaces instead of fixed blue-gray fills.
  • Standalone ship and vehicle pledge galleries keep RSI's native zoom button interactive beneath the custom enlarge icon, so gallery images open in both browser builds.
  • Firefox Pledge Store detail enhancements now resolve their lazy feature modules from the extension API global, so ship, standalone-ship, gear, and package pages initialize their redesigns.
  • Standalone ship browse cards now match their product titles to the longest exact base-model name in RSI's Ship Matrix, so variant pledge URLs still show the correct manufacturer name and logo. Exact profile URLs remain preferred, unknown or ambiguous cards stay unlabelled, and Firefox logo URLs resolve through the isolated extension runtime.
  • Pledge Store browse Add to Cart buttons now anchor the chevron near the right edge and shift the label left, reserving a clear gap between the label and arrow.
Privacy, in plain language

Your saved choices stay in your browser.

Settings and saved feature data stay in your browser. RSI Enhanced has no analytics or telemetry and does not send saved data to the developer. Optional tools may request RSI page data, public ship prices from the SC Wiki API, or funding history from Google Sheets when you use them. Read the full policy for details.
