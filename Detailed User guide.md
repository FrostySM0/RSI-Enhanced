RSI Enhanced

Detailed user guide for version 0.13.48

RSI Enhanced lets you adjust the look of Star Citizen’s RSI website and adds optional tools to Spectrum, My Hangar, Roadmap, Funding Goals, and other RSI sections. Choose which parts of the extension you want to use in its settings. RSI’s own links, account actions, and page controls remain available alongside the added styling and tools.

The extension is designed for desktop Chrome 118 and later. It also supports compatible Chromium browsers, including Microsoft Edge, Opera, and Brave.

Using the settings

Open the RSI Enhanced extension popup to configure its appearance, page layout, and optional features. Changes appear in the preview as you edit, but they remain drafts until you choose Save changes. Saving updates open supported RSI pages. Reset defaults restores the appearance and feature settings; saved threads, favourites, and hidden-user choices are kept separately. If pressing save changes and no change is visible then please reload the page and try again.

Appearance

Choose one of 16 colour themes: Spectrum Enhanced, OLED Black, UEE Navy, Anvil Industrial, Aegis Tactical, Origin Luxury, Chris Roberts, Drake Industrial, Crusader Sky, RSI Corporate, Nebula, Aurora, Eclipse, Xi’an Jade, Pyro Ember, or Terra Frontier. The Chris Roberts theme gives Spectrum text and controls a deliberately distorted cyan and magenta holographic effect. Choose a custom accent colour if you want to adjust the theme, or return to the theme’s original accent.

You can also choose the font used by extension-styled areas. Select Site default to keep each area’s existing font, or choose Arial, Segoe UI, Verdana, Tahoma, Trebuchet MS, System UI, or Comic Sans. The selected font is supplied by your computer; Comic Sans falls back to a system sans-serif font if it is unavailable.

Layout

Forum width can fill the space beside Spectrum’s sidebar or use a percentage or pixel value. Compact, Balanced, and Comfortable density settings adjust spacing, and the post and message text size can be set from 13 to 20 pixels. Choose Circle, Rounded, or Square avatars, and select Gold, White, or Off-white for developer post text. Gold keeps Spectrum’s original developer text colour.

Forum replies can use Threaded, Compact threaded, Flat, Card stack, Bubble, or Conversation stream layouts. Threaded layouts show reply depth with nested spacing and connecting lines; Flat presents replies in a single level; the other layouts give posts different surface and grouping treatments. Conversation stream also labels the parent post a reply belongs to. The popup previews the selected theme and comment layout before you save.

Spectrum

Spectrum settings are separate so you can enable only the parts you want. The shared theme and sidebar styling, Forums, Chat, Messages, Friends, saved threads, notification filters, and enhanced post blocks each have their own switch. Messages and Friends remain independently styled when the shared Spectrum theme is turned off; Friends styling is also separate from Chat styling.

Theme, sidebars, Messages, and Friends

The shared Spectrum appearance applies your chosen colour theme to the supported interface and gives the left sidebar and bookmark list a coordinated style. Bookmarks use a bookmark glyph instead of a circular avatar, with distinct icons for forum channels and live chats. Unread items are marked with amber signal bars. The Spectrum community home uses the selected theme for its blank page backdrop where supported, while native page artwork and panels keep their usual layout. Your chosen avatar shape also applies to the shared RSI account avatar in the platform header and account panel.

The Messages panel styling switch controls the Messages drawer independently. The drawer has a solid header, clearer text and controls, and a conversation list designed to fit the Friends and Notifications panels. Its header reports the current conversation and unread counts. Search conversations, start one with new, open a conversation, or close it from the list using Spectrum’s existing controls.

The Friends panel styling switch controls the Friends drawer independently of Chat. It updates the panel’s presentation while keeping Spectrum’s friend list, presence details, filtering, and controls available. Chat styling continues to control the chat room and Online Users panel.

Forums, saved threads, and notifications

Forum pages use the available desktop width beside Spectrum’s sidebar. Density, text size, avatar shape, and reply layout follow the settings you choose. Discussion posts use readable typography, prominent avatars, and clear post surfaces. Nested replies are easier to follow, and adjacent single-image attachments can share a row when there is room. Spectrum’s media links and post controls remain usable.

When you open a direct link to a reply, Extend conversation can show its parent replies back to the original post. Parent posts are identified, and the reply you opened is highlighted. Reply actions open Spectrum’s native composer. This follows the reply’s parent chain rather than loading unrelated branches.

Use the discussion controls to save a thread or remove it from your saved list. Saved threads are stored on your device and updates are shared between open RSI tabs. The notification filter lets you show All, Replies, Votes, Mentions, or Moderation notifications. A count reports how many are currently shown, while Spectrum’s own hidden states remain respected.

Enhanced post blocks hide posts from selected authors on your screen. On a Spectrum profile, Block and remove posts saves the local hide preference and also uses Spectrum’s native Block action. Show posts again clears the local hide preference; use Spectrum’s own Unblock action separately if you also want to undo the account block. The Remove posts controls in the native Blocked Users area only manage local hiding. J3PT is included as an initial local-hide choice, which you can remove or change. This however is enabled by default.

Chat

Chat styling gives the Message of the Day, channel navigation and title, message list, notification pop-ups, and chat settings a coordinated appearance. Consecutive messages from the same author are grouped, and mentions of your signed-in name are emphasized so they are easier to spot. The Online Users panel follows the same styling while retaining Spectrum’s presence colours, scrolling, filtering, links, and controls. Channel navigation and message actions continue to use Spectrum’s native controls.

RSI website sections

Each module below has its own switch in the RSI website settings, except Comm-Link and Patch Notes, which share one switch. The selected theme, font, and avatar shape apply wherever a module supports them. Styling changes the presentation of RSI’s content; RSI continues to provide the account, purchase, and navigation actions.

Account and profile

Account settings panels use theme-aware surfaces, clearer labels and details, accent-coloured links, and a visible keyboard focus. The currently selected rows are easier to identify. RSI continues to manage the account fields and their actions. The avatar shape setting also applies to the account avatar in the platform header and account panel.

My Hangar

My Hangar covers My Gear and the supported account pages for Game Access, My ROMs, Buy Back, Tickets, RSVP, Games Library, and Electronic Access. The Hangar keeps RSI’s existing pledge cards, information, links, and actions, with a desktop layout that uses the available width. Gear can be viewed in List or Grid layouts, and expanded items use a grid for their contents.

The page-size control lets you show RSI’s default 9 items, or you can select it to show 18, 36, or all items. Search can look across Hangar pages for pledge or package names, listed contents, and expanded pledge details. Filters include item type, LTI, giftable or reclaim status, Warbond, melt value, and Ship Paint; sorting includes Recently added, Name A–Z, and Highest value. The page also shows the visible item range and page count.

You can favourite standalone ships and packages containing ships. Favourites are saved locally, promoted on the first page, and can link to their original pledge on another page. Package cards show the contained ship’s name and thumbnail; pledge ID, base pledge name, and melt value appear when RSI supplies that information. Export the displayed information as CSV or Hangar Transfer JSON. These files may contain pledge details associated with your account, so review them before sharing.

Search, filters that span pages, export, refresh, and saved cross-page views may read additional Hangar pages from RSI when you use them. These are same-site, read-only requests. The normalized Hangar index is cached in browser storage for 15 minutes. Existing Hangar images can be opened in a larger image view when RSI provides a verified source image, with the original thumbnail available as a fallback. The Hangar Log uses an activity timeline while retaining RSI’s entries and controls.

Pledge Store

Product information in the Pledge Store uses your selected font and theme text colours, with category and discount details given a quieter treatment. Product names, prices, artwork, ribbons, links, and purchase controls remain standard. Keyboard focus on product links is made visible.

Ship Matrix

The Ship Matrix uses your selected font, readable text, and theme-aware surfaces for its headings, stat boxes, and filters. The disclaimer and keyboard focus are easier to read. RSI’s ship information, artwork, comparison ruler, sorting, dragging, and horizontal scrolling keep their normal behaviour and geometry.

Organisations

Organisation listings, profile pages, and member directories use the available desktop width and clearer content panels. Organisation profiles retain their banners, details, activity, media, and history, manifesto, and charter sections. Profile layout groups the existing information into easier-to-read sections. Links from the profile’s Connect panel are shown when they do not require credentials.

Member directories keep search, filters, profile links, privacy restrictions, and scroll loading. Joining an organisation and the visibility of its members are retained.

Comm-Link and Patch Notes

Comm-Link and Patch Notes share one settings switch. Their feed listings use coordinated dark surfaces and clearer text, with improved artwork presentation and hover and keyboard-focus feedback. Patch Notes cards retain their artwork and categories. Comm-Link articles use more readable typography while keeping their native content and navigation. Each page has its own title icon. Search, language, category, and page controls remain available with clearer filter menus and reset controls.

Roadmap

Release View cards keep RSI’s artwork, status, details, and navigation, with stronger text contrast and a more readable description size. Released, Committed, and Tentative statuses are easier to distinguish. Its header can show the Live Version, Latest Roadmap Roundup, and PTU status; available version and roundup links remain clickable, and an unavailable or closed PTU will be shown as PTU closed.

Search current and previous-release cards, filter by status or category, and jump to a result. Press Ctrl+K or Command+K to focus search. Use the arrow keys to move through results, Enter to open the first match, and Escape to dismiss the results (All categories must be expanded to be searchable). The selected card is outlined, and search works with RSI’s release detail pop-out. Numeric patch headings are labelled Alpha; named releases keep their names. Card metadata includes the modified date and card slug when CIG provides them. Select a card image to open its supplied source using the browser’s normal image controls.

The Roadmap navigation preference controls which view opens from CIG’s main Roadmap navigation entry: Release View or Progress Tracker. Direct links and the view switcher inside the Roadmap keep their own destinations.

Funding Goals

Funding Goals keeps CIG’s live funding and Star Citizen totals, stretch goals, and Hour, Day, Week, and Month chart controls. It adds funding and citizen change figures for the latest hour and the last 24 hours, plus Quarter and Year chart ranges. The Year range loads when selected (Thank you to CCUGame for the spreadsheet).
The extra history comes from a public hourly Google Sheet. Its displayed time, age, and most recent successful check help you tell how current the data is. Results are cached locally; if the sheet is delayed or unavailable, the extension identifies stale or saved data instead of presenting invented values. Google receives ordinary request details such as your IP address and request time, but the sheet request does not include RSI account or Hangar data.

Dev Tracker

Dev Tracker presents RSI’s posts in a full-width feed grouped by date, with clearer post titles and author information. Each developer response can show the Spectrum post it answers. Long parent posts and developer responses can be expanded or collapsed separately, so you can read the full context without losing your place in the feed. Developer text uses the Gold, White, or Off-white setting. Links open the corresponding native Spectrum thread and Reply composer; RSI’s Auto Load control remains available.

Data and permissions

RSI Enhanced runs on RSI pages so it can apply your settings, follow RSI’s in-page navigation, and provide the tools you enable. It requests the browser’s storage permission and a fixed Google Sheets host permission for Funding Goals. Preferences, saved threads, hidden-user choices, favourites, and the Hangar index are stored in your browser’s extension storage.

The extension does not include analytics or telemetry and does not upload your settings or Hangar details to an extension developer service. Conversation expansion and Hangar page tools make read-only requests to RSI on the same site when you use them. Funding history is read from the public Google Sheet described above.No user information is gathered for external use or to be sold to third parties.

Install via load unpacked

1. Extract the package ZIP.
2. Open `chrome://extensions` in Chrome or in your chromium based browser.
3. Turn on Developer mode and choose Load unpacked.
4. Select the extracted `RSI-Enhanced-vX.XX.XX` folder containing `manifest.json`.
5. Refresh any RSI tabs that were already open.
6. Go to the extensions icon and select RSI Enhanced and go through the settigns.

For focused package checks, see `TESTER-INSTRUCTIONS.txt`.
